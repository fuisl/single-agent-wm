# 在线 RL 第一轮结果：地图辅助损失没有带来可测的成功率提升，但测试设计有问题

日期：2026-10-20｜两组设置相同：DreamerV3 50M，16 架无人机并行，150 万环境步，种子 0，λ = 0 / 30

## 一句话结论

**两组在三个测试集上没有显著差别。** 原因不是"记忆没用"，而是这一轮的测试没能测到记忆：U 形陷阱太简单，两组都是 100%；C 形陷阱太难，而且超出了训练分布，两组几乎都在陷阱里面就撞墙了，根本没走到需要记忆的那一步。

## 1. 训练

| | 基线 | + 地图损失 λ=30 |
|---|---|---|
| 训练场景到达率（训练末期） | 约 98% | 约 98% |
| 训练耗时 | 约 4.7 h | 约 7 h（每步要额外算地图标签） |

两组学习速度和最终水平基本一样（图：rl_base_curves.png / rl_map30_curves.png）。

## 2. 固定测试集评测（各 100 次，同一批场景）

| 测试集 | 基线 | + 地图损失 λ=30 |
|---|---|---|
| 一般场景（与训练同分布） | 99% 到达，1% 碰撞 | 98% 到达，2% 碰撞 |
| U 形陷阱（起点在陷阱外，终点在背后） | 100% | 100% |
| C 形陷阱（起点在腔体内，面朝后墙） | 14% 到达，86% 碰撞 | 9% 到达，90% 碰撞 |

到达率在 10% 左右时，100 次评测的统计误差约为 ±3%，所以 14% 和 9% 之间的差别不显著。

## 3. 为什么没测出差别（图：online_traj.png）

- **U 形陷阱太简单**：起点在陷阱外面，陷阱一开始就在视野里，策略直接绕过去就行，不需要记住看不见的东西
- **C 形陷阱失败在第一步**：86–90 次碰撞都发生在**腔体内部**，平均起飞后约 2 秒，无人机还没离开腔体。也就是说，策略没学会在狭窄空间里掉头、从 1.2–1.8 m 的缺口钻出去。训练场景里从来没有"起点在陷阱里"的情况，这对两组都是没见过的场景
- 所以，需要记忆的阶段（飞出缺口以后，绕着看不见的墙走向终点）两组都没走到

## 4. 中途修复的两个问题

- **评测脚本时序错位**：第一次评测时，第 2、3 个测试集的观测比动作晚了一步。修复后重新评测，上表是修复后的结果（修复前后结论相同）
- **重置后第一帧深度过期**：传送到新场景后，第一帧深度图还显示旧障碍。评测服务器已加一次额外渲染修复。训练数据里每条 episode 只有第一帧受影响，影响可以忽略

## 5. 建议的下一步

要真正测出记忆的作用，需要让测试场景**必须依赖记忆、又在策略的能力范围内**：

1. **训练分布加入"陷阱内起飞"**：比如 30% 的训练 episode 从 C 形陷阱或 U 形陷阱内部起飞，让两组都先学会钻出来
2. **重新设计测试**：
   - U 形陷阱改为"起点在 U 形内部、面朝后墙"，必须先掉头飞出开口，再绕到背后的终点。飞出之后后墙已经在身后，看不见了
   - C 形陷阱保持不变，作为更难的版本
3. 两组用新分布重新训练（约 12 小时），再评测
